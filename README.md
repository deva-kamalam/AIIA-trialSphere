# AIIA TrialSphere

Clinical trial management system (CTMS) for Ayurveda clinical research at AIIA: study and
protocol management, participants and visits, eCRFs, ethics and regulatory tracking,
pharmacovigilance, documents, audit trail, CDISC/FHIR interoperability and analytics.

The frontend lives in [`app/`](app/) (React, TypeScript, Vite, Tailwind CSS, Recharts) and runs
on fictional demo data. See [`app/README.md`](app/README.md) to run it and [`PLAN.md`](PLAN.md)
for the design plan.

```bash
cd app
npm install
npm run dev
```
